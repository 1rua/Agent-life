# 区分受保护模式与开发者信任模式

Android 宿主默认运行在受保护模式，只接受平台内核能够强制限制的 WASM 插件；插件界面与配置由宿主根据声明渲染，执行受到时间、内存、存储、网络和并发限额约束。任何作者都可以自行签名并分发插件：首次安装由用户确认作者密钥，后续更新必须保持同一密钥，密钥变更视为新的信任关系；签名证明来源和更新连续性，不证明代码安全。任意 Kotlin、Java、DEX 或本机代码只能在用户明确开启的开发者信任模式中进入宿主进程，此时插件被视为平台内核的一部分可信代码，界面必须持续说明宿主无法隔离它对既有权限和数据的访问。
