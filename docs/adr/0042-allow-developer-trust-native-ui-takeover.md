# 允许开发者信任原生插件接管宿主界面并保留受保护模式

Open Android Intelligence 保留默认的受保护 WASM 插件路径及宿主声明式界面，同时允许任何插件选择原生运行类型并通过版本化扩展接管主导航、业务页面、对话、附件、助理界面、主题和动画；用户一次开启全局开发者信任模式后，当前及以后安装的原生插件均可作为宿主可信代码运行，不再逐包请求原生信任确认。全局信任不允许后台自动安装或跳过包身份、作者密钥和摘要验证，原生插件仍由用户显式安装且默认手动更新。启用该模式即接受平台内核无法隔离原生插件对宿主既有权限、数据、界面、应用内确认和审计观察的访问或影响，完整 APK、F-Droid、企业托管与侧载版优先支持该能力，Google Play 发行兼容性留待后续评估。原生插件应使用受支持的界面扩展而不是反射或运行时补丁；宿主保留先于插件加载的安全模式、全局停用和崩溃恢复入口，但这是恢复机制而非对同进程恶意代码的沙箱保证。
