- **相对路径导入**: 所有新增模块和代码均使用相对路径导入，无绝对路径硬编码。
- **无破坏性删除**: 严格遵守文件安全规范，使用回收站/临时目录安全隔离。
- **单状态源与不可变单向数据流**: `conversation-domain` 模块采用严格的 Reducer 和不可变 State 架构。
- **无伪造实现**: 移除所有假数据与虚假状态，完全接入真实 Gateway Protocol v2。
